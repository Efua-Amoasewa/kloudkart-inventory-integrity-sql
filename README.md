# Kloud Kart — inventory and order integrity on PostgreSQL

Work for the Kloud Kart Inventory & Order Management lab (DE03 SQL for Data Professionals):
stop overselling, make the Monday customer report fast, roll low stock up through the
category tree, and keep an audit trail of every stock movement — all on the one
PostgreSQL server Kloud Kart already has.

Run instructions and the deliverable map are added as the work lands.
